## ¿Qué es Auranas?

Auranas es una aplicación web desarrollada por Xyon Platforms. Construida con JavaScript y Node.js, lista para despliegue en servidor propio.

## ✨ Funcionalidades

- Interfaz web moderna y funcional
- Gestión y administración de contenido
- Despliegue self-hosted

## 🛠️ Stack técnico

| Capa | Tecnología |
|------|----------|
| Frontend | HTML + CSS + JavaScript |
| Backend | Node.js |

## 🚀 Instalación

```bash
git clone https://github.com/mkandreum/auranas.git
cd auranas
npm install
npm start
```
